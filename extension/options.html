Optional. The extension works without a token.

Why you might want one. Lookups work without a token, but anonymous requests are throttled first and hardest — a long page can crawl. A token raises your limit.

Where it is kept. In this browser's extension storage, on this machine. It is sent only to courtlistener.com, in the header of your own lookups. There is no account and no server of ours — there is nowhere for us to receive it.

How to get one, free:

  1. Make an account at courtlistener.com
  2. Open your API token page
  3. Copy the token and paste it above

You can revoke it on that same page at any time.
